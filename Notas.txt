Los comandos necesarios para instalar Node.js, npm y snarkjs en Ubuntu mediante WSL, en orden. Ejecuta todo desde la terminal de Linux, no desde PowerShell.

0. Instalar El Subsistema de Windows para Linux (WSL)

1. Actualizar e instalar dependencias

sudo apt update
sudo apt install -y curl


2. Instalar nvm y Node.js

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.7/install.sh | bash


Cargar nvm:
source ~/.bashrc


Instalar Node.js 24 LTS:
nvm install 24
nvm use 24


3. Instalar snarkjs

npm install -g snarkjs@latest


4. Verificar las instalaciones

node -v
npm -v
snarkjs --help
circom --version


Si los comandos muestran sus versiones o la ayuda correspondiente, las herramientas están funcionando.

Nota: si `nvm` no se reconoce después de ejecutar `source ~/.bashrc`, cierra y vuelve a abrir la terminal o ejecuta ese comando nuevamente. Si `circom` no se reconoce, tendrás que instalarlo o configurar su ruta dentro de WSL por separado.
